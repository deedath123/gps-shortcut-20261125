One-line comedy entry for the [make.fun bounty "The GPS Swears It Was a Shortcut"](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

## Entry

`main.py` prints a single line — the GPS's own excuse, in its own voice, for sending the driver down the wrong road — to `/output/entry.txt`:

> Look, the map swore this cul-de-sac shaved nine minutes off your trip, so I trusted it, and now the bride is glaring at us through her veil while her wedding starts in four minutes.

## Run

```sh
python3 -P -s main.py
```

Deterministic, standard library only. It writes exactly one line (181 characters) to `/output/entry.txt`.
